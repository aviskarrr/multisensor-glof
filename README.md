# GLOF Project

Repository structure for the Glacial Lake Outburst Flood (GLOF) project.

## Structure

- `data/`: raw, processed, inventory, and reference data
- `gee/`: Google Earth Engine assets and exports
- `notebooks/`: analysis notebooks
- `src/`: Python source code for preprocessing, features, modeling, and evaluation
- `models/`: saved model artifacts
- `outputs/`: figures, maps, tables, and predictions
- `docs/`: documentation
